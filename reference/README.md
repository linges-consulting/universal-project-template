# Reference materials

This directory holds approved supporting material, not authoritative specifications. Use `designs/` for visual references, `samples/` for small anonymized fixtures, `integrations/` for licensed third-party examples, and `legacy/` for migration context. Before tracking anything, verify usefulness, sensitivity, provenance, license, size, and retention requirements. Keep private or production materials outside Git in an approved secure system and link to them only when access-controlled.
